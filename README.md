# KashCake website

The site at https://kashcake.onekash.org: the landing page and the beta instructions for
[KashCake](https://github.com/OneKashLabs/KashCake). Built with Docusaurus and published to GitHub
Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm ci
npm start          # local preview with live reload
npm run build      # static site in build/
npm run serve      # serve build/
```
